# 셋업 사용자 여정 (v4 기준)

날짜: 2026년 8월 28일
기준 문서: 「개선된 기획 고도화 v4」

여정의 뼈대는 도시의 시간 축이다. 사용자는 온보딩에서 Lv.1 도시를 받고, 매일 도시를 확인하고, 매주 주간 코인을, 매월 월간 코인을 받아 도시를 키운다. 금융 기능(분석·자동 준비·추천)은 각 단계에서 도시를 통해 만난다.

---

## 보상 루프 요약 (재화 흐름)

| 재화 | 획득 (기준: 소비를 잘했다 = 월간 계획 준수) | 사용 | 주기 |
| --- | --- | --- | --- |
| 주간 코인 (가칭 '망치') | 주간 마감 페이스 1.05 이하 카테고리당 | 꾸미기·생활 요소 (가로수, 벤치, 간판, 조명, 계절 소품) | 짧다 — 매주 성실함을 즉시 보상 |
| 월간 코인 (가칭 '금괴') | 월말 확정 '정상' 이상 카테고리당 + '성장' 추가 + 전체 정상 보너스 | 건물 레벨 업그레이드, 대형 시설, 부지 확장 | 길다 — 완주만이 스카이라인을 바꾼다 |
| 랜드마크 | 코인 구매 불가. 자동 준비 3개월 무사고, 구독 해지, 할부 완납, 저축 3개월 달성 | (소유 자체가 보상) | 행동의 기념비 |

- 주간 코인 ↔ 월간 코인 교환 불가. 재화 특색과 보상 주기 설계 보호.
- 현금 구매 불가. 출석·클릭·공유에는 지급하지 않음 — 보상 기준은 '소비를 잘했다' 하나.

## 엣지 여정

| 상황 | 처리 |
| --- | --- |
| 카테고리 9개 이상 | 지출 비중 상위 8개가 팔방 부지, 나머지는 외곽 확장 부지 |
| 예산 미설정 카테고리 | 회색 '미개발 부지'. 계획을 세우면 건물이 선다. 강제하지 않음 |
| 월중 신규 카테고리 | 외곽 부지 '측량 중', 익월부터 판정 |
| 이사·여행·경조사 | '특별 공사 기간' 마킹 시 강등 제외 (연 2~3회) |
| 환불·결제 취소 | 소진률 재계산, 상태 자동 갱신. 지급된 코인은 회수하지 않음 (신뢰 우선) |
| 알림 피로 | '조용한 모드' (주 1회). 주간 정산이 진입 계기가 된다 |
