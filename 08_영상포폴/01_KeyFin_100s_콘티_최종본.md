# KeyFin 100초 영상 콘티 최종본

## 기본 구성

- 총 길이: **100초**
- S01~S12: 각 **8초**
- S13: **4초**
- 화면 비율: **16:9**
- 현실 세계: **M1 현실 윤 씨 + M3 현실 방**
- KeyFin 세계: **M5 KeyFin 아바타 + M2 AI 고양이 + M4 KeyFin Room**
- S04부터 현실 세계와 KeyFin 세계는 **렌더링 스타일 자체가 달라야 한다.**
  - 현실: 실사 / 따뜻한 야간 생활 공간
  - KeyFin: stylized 3D CGI / 보라·블루 / 캐릭터가 실제로 사는 애니메이션 공간

## 중요 연출 고정사항

### S04
- A는 **3초를 충분히 유지**한다.
- A→B는 하드컷이 아니라 **3분할 전체가 천천히 어두워져 완전한 검은 화면**이 된다.
- B는 **검은 화면 이후** 공식 `KeyFin` 로고가 나와야 한다.
- 철자는 반드시 **KeyFin**. `KeyFinn` 금지.
- C는 현실 방이 아니라 **M4와 같은 stylized 3D 캐릭터 세계**다.
- C에 등장하는 인물은 **M5만**. M1 실사 인물 금지.
- M5는 **입을 끝까지 닫고**, 립싱크·말하기·입 벌린 웃음·치아 노출 금지.

### S07
- 고양이는 단순 마스코트가 아니라 **사용자 데이터를 기반으로 답하는 AI 금융 코치**다.
- `질문 → 데이터 기반 코칭 구조 → 맞춤 답변` 흐름이 명확해야 한다.

### S12
- 핵심은 구매를 막는 것이 아니다.
- **같은 소비를 하되, KeyFin을 사용했을 때 월말 결과가 달라지는 것**을 보여준다.
- 가능하면 A의 역재생은 실제 S01/S02 footage를 편집에서 재사용한다.

### S13
- 타이포그래피는 생성 영상에 맡기지 않고 **후반 모션그래픽**으로 처리한다.
