# [서비스명] 서비스 기획서 (템플릿)

> 서사형 문서가 "왜 만드는가"를 설득한다면, 이 템플릿은 "무엇을 어떤 기준으로 만들고 어떻게 검증하는가"를 고정한다.
> 각 섹션의 인용 블록은 작성 가이드다. 내용을 채운 뒤 가이드 블록은 삭제한다.

---

## 문서 규약

| 표기 | 의미 |
| --- | --- |
| `📊` | 정량 데이터로 검증이 필요한 주장 |
| `❓` | 외부 의존(API 명세·정책 등) 확인이 끝나지 않은 항목 |
| `TBD` | 결정되지 않은 값. 담당자와 기한을 함께 적는다 |
| `P0 / P1 / P2` | MVP 필수 / MVP 이후 / 범위 외(향후) |

| ID 체계 | 대상 | 예시 |
| --- | --- | --- |
| `F-xx` | 기능 요구사항 | F-02 셀프 월급 산정 |
| `NFR-xx` | 비기능 요구사항 | NFR-01 실행 안전장치 |
| `AC-xx-n` | 수용 기준(Acceptance Criteria) | AC-02-1 |
| `T-xx` | 기술 도전 과제 | T1 원장 정합성 |
| `R-xx` | 리스크 | R-01 |
| `Q-xx` | 오픈 이슈·결정 대기 | Q-01 |
