# 1. 개요

## 1-1. 한 줄로 말하면

```
 ┌────────────────────────────────────────────────────────┐
 │                                                        │
 │   들쭉날쭉 들어오는 돈을,                              │
 │   매달 똑같이 나가는 돈에 맞춰                         │
 │                                                        │
 │   우리가 대신 정리하고, 대신 옮겨준다.                 │
 │                                                        │
 └────────────────────────────────────────────────────────┘
```

**바뀌는 모습 (예시)**

```
  지금                              셋업을 쓰면

  3월  ████████████  92만           3월  ██████  50만
  4월  ████░░░░░░░░  31만           4월  ██████  50만
  5월  ███████░░░░░  58만    ──▶    5월  ██████  50만
  6월  ██░░░░░░░░░░  15만           6월  ██████  50만

  매달 얼마 쓸지 모른다              매달 같은 날, 같은 금액
```

서비스 이름이 하는 일 그대로입니다. 월급 구조, 예산 나누기, 저축 통로를 **대신 세팅(Setup)** 해 줍니다.

## 1-2. 이 문서에서 쓰는 말

용어부터 맞추고 갑니다. 회의에서는 오른쪽 표현을 씁니다.

| 기획서 용어 | 회의에서 쓸 말 | 뜻 |
| --- | --- | --- |
| 머니 플로우 엔진 | **엔진** | 돈을 계산하고 실제로 옮기는 우리 서비스의 심장 |
| 원장 | **통합 장부** | 여러 계좌·카드를 하나로 합친 장부 |
| 가상 봉투 | **봉투** | 식비·교통비처럼 항목별로 나눠둔 이번 달 예산 |
| 셀프 월급 | **셀프 월급** | 내가 나에게 주는 월급. 매달 같은 날 생활비 통장으로 들어옴 |
| 사전 충당 | **미리 채우기** | 카드값·월세 나가기 전날 그 통장에 부족한 돈을 미리 넣어두기 |
| 파킹(스윕) | **자동 저축** | 달 마지막에 남은 돈을 적금으로 자동 이체 |
| 대사 | **장부 맞춰보기** | 실제 거래와 우리 장부가 맞는지 대조하는 일 |
| Safe-to-Spend | **써도 되는 돈** | 지금 써도 괜찮은 금액 |
| 수입 측 인텔리전스 | **지원금 찾아주기** | 받을 수 있는 청년 정책을 찾아 알려주는 기능 |
| 넛지 | **살짝 알려주기** | 막지 않고 알림으로만 알려주는 방식 |

## 1-3. 무엇이 바뀌었나

컨설팅에서 네 가지를 지적받았고, 그 네 가지가 이번 개편의 전부입니다.

```
   예전                                      지금
 ┌──────────────┐                        ┌──────────────┐
 │  정책 추천   │  메인                  │    엔진      │  메인
 │  (정보 제공) │                        │ (돈을 옮김)  │
 └──────────────┘                        └──────────────┘
 ┌──────────────┐                        ┌──────────────┐
 │  계산기들    │  부가                  │  정책 추천   │  부가
 └──────────────┘                        └──────────────┘

   돈을 보여주기만 했다        ──▶        돈을 실제로 움직인다
```

| 지적받은 것 | 왜 그랬나 | 어떻게 바꿨나 |
| --- | --- | --- |
| 핀테크 느낌이 안 난다 | 메인이 정보 제공이었고, 금융 기능은 전부 계산기였다. 돈이 실제로 움직이지 않았다 | 돈을 실제로 옮기는 엔진을 메인으로 |
| 청년 정책이 그렇게 크지 않다 | 정책이 메인이라 자격 없는 사람에게는 빈 껍데기였다 | 정책을 뒤로 빼고 덤으로. 정책이 없어도 서비스는 돌아감 |
| 돈을 모으는 기능이 없다 | 쓰는 돈과 들어오는 돈만 다뤘다 | 봉투 예산 + 자동 저축 + 목표 세우기를 새로 넣음 |
| 자산 관리가 메인이어야 하지 않나 | 맞지만 그냥 뒤집으면 토스·뱅샐의 못한 버전이 된다 | 뒤집지 않고 합침. 자산 관리가 메인, 정책·예적금·대출은 그 안의 부품 |

# 2. 문제 정의

## 2-1. 들어오는 돈은 들쭉날쭉, 나가는 돈은 일정하다

```
  들어오는 돈 (예시)              나가는 돈 (예시)
  ──────────────────────         ──────────────────────
  3월  ████████████  92만        월세    ████████  50만
  4월  ████░░░░░░░░  31만        통신비  █░░░░░░░   6만
  5월  ███████░░░░░  58만        할부    ███░░░░░  18만
  6월  ██░░░░░░░░░░  15만        교통    █░░░░░░░   7만

  ↑ 매달 다르다                  ↑ 매달 똑같은 날, 똑같은 금액
```

여기서 두 가지 일이 벌어집니다.

| 수입이 적은 달 | 수입이 많은 달 |
| --- | --- |
| 고정비를 내고 나면 남는 게 없다 | 남은 돈이 관리되지 않고 그냥 소비로 사라진다 |

## 2-2. 계획은 세우는데 실행에서 끊긴다

```
  예산 세우기  ──▶  은행 앱 열기  ──▶  이체하기  ──▶  저축하기
      ○                  ×

                    여기서 끊긴다
              (가계부 앱이 도와주지 않는 구간)
```

"이번 달 식비 30만"이라고 적어도, 옮기고 내고 모으는 일은 사용자가 직접 해야 합니다.
예산을 못 지키는 이유는 의지가 약해서가 아니라 **아무도 대신 실행해 주지 않기 때문**입니다.

## 2-3. 받을 돈과 새는 돈이 따로 논다

```
        받을 수 있는데 못 받는 돈              필요 없이 나가는 돈
        ┌──────────────────────┐            ┌──────────────────────┐
        │  월세지원  최대 480만│            │  할부 수수료         │
        │  국취제    최대 300만│            │  불필요한 이자       │
        └──────────┬───────────┘            └──────────┬───────────┘
                   │                                   │
                   ×  연결 안 됨                       ×  연결 안 됨
                   │                                   │
                   └─────────────────┬─────────────────┘
                                     ▼
                               내 현금 흐름
```

정책 서비스는 알려만 주고, 카드 앱은 내역만 보여줍니다.
**찾아서 넣어주고, 막아서 저축으로 돌리는** 연결을 아무도 하지 않습니다.

## 2-4. 기존 서비스는 어디까지 하고 멈추나

| | 기록 | 계획 | 실행 | 지원금 연결 |
| --- | :---: | :---: | :---: | :---: |
| 가계부 (뱅샐 등) | ○ | △ | × | × |
| 예산 앱 (YNAB) | ○ | ○ | × | × |

| 은행 자동이체 | × | × | △ (금액 고정) | × |
| **셋업** | **○** | **○** | **○** | **○** |

# 3. 솔루션

## 3-1. 네 단계가 계속 돕니다

```
     ①  통합 장부  ──────────────▶  ②  계산
        내 돈이 어디에                  이번 달 얼마까지
        얼마 있는지 기록                안전한지 계산

        ▲                                        │
        │                                        ▼

     ④  결과 반영  ◀──────────────  ③  실행
        쓴 결과를 보고                  계산한 대로
        다음 달에 조정                  실제로 옮김
```

| 단계 | 하는 일 | 사용자에게는 이렇게 보임 |
| --- | --- | --- |
| ① 통합 장부 | 계좌·카드·봉투를 한 장부로 합침 | "내 돈이 지금 어디에 얼마 있지" |
| ② 계산 | 최근 수입이 얼마나 오르내렸는지 보고 안전한 금액을 정함 | "이번 달은 50만 원까지 괜찮아요" |
| ③ 실행 | 이체·납부·저축을 직접 수행 | "생활비 넣어뒀고, 월세도 미리 채워뒀어요" |
| ④ 결과 반영 | 실제 쓴 내역을 감지해 다음 달 계산에 넣음 | "지난달 식비가 남아서 이번 달은 줄일게요" |

다른 서비스는 ①②까지 하고 멈춥니다. **우리는 ③을 합니다.**

## 3-2. 자주 받을 질문 두 개

```
 "그거 은행 자동이체 아니야?"
 ─────────────────────────────────────────────────────────
                    은행 자동이체            셋업
  금액을 정하는 건    사용자                 엔진이 계산
  바뀌는 시점        사용자가 바꿀 때까지     매달 다시 계산
  결과를 보나        안 봄                   다음 달 금액에 반영


 "그거 가계부 아니야?"
 ─────────────────────────────────────────────────────────
  가계부   기록 ──▶ 끝
  셋업     기록 ──▶ 장부 맞춰보기 ──▶ 미리 채우기 ──▶ 자동 저축
                                          └─ 카드값 연체를 막는 일까지 함
```

## 3-3. 메인과 부품

```
        ┌───────────────────────────────────────────┐
        │                엔진 (메인)                │
        │                                           │
        │          통합 장부      셀프 월급         │   이것만으로
        │         미리 채우기      자동 저축        │   서비스가 성립
        └───────────────────────────────────────────┘
                 ▲                        ▲
        ┌────────┴────────┐      ┌────────┴────────┐
        │ 지원금 찾아주기 │      │  할부 줄여주기  │   있으면 더 좋은 덤
        └─────────────────┘      └─────────────────┘
```

기존에 만들던 것을 버린 게 아닙니다. 정책 검색 AI, 할부 계산, 소비 분류 모델은 전부 살아 있고 **위치만 바뀌었습니다.**

받을 수 있는 정책이 하나도 없는 사용자에게도 메인 기능은 그대로 돌아갑니다.

# 4. 핵심 기능

## 4-1. 기능 한눈에

위에 있을수록 먼저 만들어야 합니다.

| 기능 | 쉽게 말하면 | 루프 위치 | 담당 |
| --- | --- | :---: | :---: |
| **통합 장부 · 봉투** | 계좌마다 역할(수입·생활비·고정비·저축)을 정하고, 항목별 예산을 얹는다. 어떤 카드로 긁어도 봉투에서 딱 한 번만 빠진다 | ① | BE |
| **셀프 월급 계산** | 최근 수입 중 "적게 벌었던 달에도 감당되는 금액"을 골라 매달 지급액을 정한다 | ② | BE·AI |
| **자동 실행** | 셀프 월급 이체, 결제일 전 미리 채우기, 고정비 자동 납부, 남은 돈 자동 저축 | ③ | BE |
| **거래 감지** | 계좌·카드 내역을 주기적으로 확인해 소비를 잡고 봉투에서 뺀다 | ④ | BE |
| **안전장치** | 이체 한도, 항목별 사전 동의, 이상하면 멈춤, 12시간 전 미리 알림, 기록 남기기 | ③ 보호 | BE |
| **AI 코치** | 예산을 대신 짜주고, 결과를 말로 알려준다. 조언 옆에 바로 실행 버튼이 있다 | 전달 | AI |
| **카드값·대출 관리** | 이번 달 나갈 카드값을 매일 다시 계산하고, 연체를 막고, 할부·대출 비용을 줄인다 | 축 | BE |
| **찾아주기** | 받을 수 있는 지원금 찾기, 할부 줄이기, 결제 내역 자동 분류 | 공급 | AI |
| **캐릭터·기록** | 봉투 상태를 캐릭터 표정으로, 예산 지킨 날을 연속 기록으로 | 화면 | FE |

## 4-2. 승부처 세 가지

```
  1위  통합 장부      ──▶  "금융 시스템을 제대로 만들 줄 안다"를 증명
  2위  미리 채우기    ──▶  "우리만 하는 기능" (국내에 비슷한 서비스 없음)
  3위  셀프 월급 계산 ──▶  "우리만의 계산 방식"을 증명
```

발표도 이 순서로 갑니다. 정책 이야기부터 시작하면 "핀테크 느낌이 안 난다"는 말을 그대로 다시 듣습니다.

## 4-3. 안 하기로 한 것

무엇을 안 하는지가 무엇을 하는지만큼 중요합니다.

| 안 하는 것 | 이유 |
| --- | --- |
| 우리가 돈을 들고 있기 | 돈은 항상 은행에 사용자 이름으로 있습니다. 우리는 "옮겨 달라"고 지시만 합니다 |
| 결제 막기 | 막지 않고 알려만 줍니다. 봉투가 비어도 결제는 됩니다 |
| AI가 금액을 만들어내기 | 금액은 전부 계산 엔진이 만들고, AI는 설명만 합니다 |
| AI가 알아서 돈 옮기기 | AI는 제안만 하고, 실행은 사용자가 승인한 뒤에 합니다 |
| 문자·알림 읽어오기 | 서비스 출시 단계 이야기라 이번 범위 밖입니다 |
| 음성으로 말하기 | 들이는 비용에 비해 얻는 게 적고, 남 앞에서 금액이 소리로 나오는 문제가 있습니다 |
| 세대분리 계산기 / 정책 예보 | 나중으로 미룹니다 |

# 5. 사용 흐름

## 5-1. 처음 한 번 (첫 설정)

```
 프로필 입력
      ▼
 계좌·카드 불러오기
      ▼
 관리할 계좌 고르기 ──── 비상금·가족 계좌는 빼도 됩니다.
      ▼                  엔진은 고른 계좌 안에서만 움직입니다.
 역할 정하기 (수입 / 생활비 / 고정비 / 저축)
      ▼
 AI가 거래 내역을 보고 제안
   "월 50만 셀프 월급 + 봉투 5개 어때요?"
      ▼
 승인하고 한도 정하기
      ▼
 세팅 완료
```

## 5-2. 그다음부터 (한 달의 흐름)

```
  1일 ────── 5일 ────── 15일 ────── 24일 ── 25일 ────── 말일
   │          │          │           │       │           │
  알바비     정해진      점심 결제    카드값  월세        남은 돈
  45만       날에        식비 봉투    나갈    자동        7만
  입금       셀프 월급   자동 차감    통장    납부        자동 저축
             생활비로                 미리
             이체                     채움
```

| 시점 | 무슨 일이 일어나나 |
| --- | --- |
| 알바비 45만 입금 | 1분 안에 알아채고 "생활비 30만 넣었고, 25일 월세 나갈 통장에 20만 미리 채웠어요" 알림 |
| 지원금 발견 | 월세지원 자격을 찾아 신청 방법 안내. 받은 20만은 월세 채우는 데 들어가고, 아낀 돈은 저축으로 |
| 점심 결제 | 자동으로 "식비"로 분류해 봉투에서 차감. 식비 캐릭터가 걱정하는 표정으로 바뀜 |
| 주말 전 질문 | "여행에 5만 써도 돼?" → "여가비가 1만 2천 원 남아서 모자라요. 식비에서 4만 옮기면 돼요. 옮길까요?" |
| 달 마지막 | 이번 달 리포트 + 다음 달 예산 제안. 남은 7만 원을 적금으로 자동 이체 (12시간 전에 미리 알림) |
